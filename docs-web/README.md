# Documentación Web - Evidencias ISO 27001

Esta es la aplicación web de documentación del proyecto Evidencias ISO 27001.

## 🚀 Desarrollo

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:5173`

## 🏗️ Build

```bash
npm run build
```

Los archivos compilados estarán en `dist/`

## 📦 Despliegue

La app de documentación se despliega junto con el sistema principal. Ver el README principal para instrucciones completas.

## 📁 Estructura

```
docs-web/
├── src/
│   ├── components/        # Componentes React
│   ├── App.tsx           # Componente principal
│   ├── main.tsx          # Punto de entrada
│   └── index.css         # Estilos globales
├── package.json
├── vite.config.js
└── tsconfig.json
```

## 🎨 Tecnologías

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React (iconos)
